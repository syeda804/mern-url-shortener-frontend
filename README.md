# 🔗 MERN URL Shortener – Frontend

A modern and responsive URL Shortener application built with React.js. This frontend allows users to shorten long URLs, manage their shortened links, and access their accounts through secure authentication.

## 🚀 Features

- User Registration and Login
- Secure JWT Authentication
- URL Shortening
- Shortened URL Management
- React Router Navigation
- API Integration with Backend
- Responsive User Interface
- Local Storage Token Management

## 🛠️ Technologies Used

- React.js
- JavaScript
- CSS3
- React Router DOM
- Axios / Fetch API
- Local Storage

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/syeda804/mern-url-shortener-frontend.git
```

**2. Navigate to the project**

```bash
cd mern-url-shortener-frontend
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm start
```

The application will run at:

`http://localhost:3000`

## 🔌 Backend Integration

This frontend communicates with a Node.js and Express.js backend API.

Make sure the backend server is running before using the application.

Backend API URL (local):

`http://localhost:5000`

## 🔐 Authentication

The application uses JWT-based authentication to manage user sessions. Authentication tokens are stored in browser Local Storage.
